Session JSON

Dán ChatGPT Web session, JSON chỉ có token, JSONL nhiều dòng, hoặc kéo thả tệp JSON/TXT vào ô bên dưới.

Session được lấy ở đâu?

Đăng nhập ChatGPT, mở https://chatgpt.com/api/auth/session, sao chép toàn bộ JSON rồi dán vào đây.

Công cụ nhận JSON session đầy đủ, JSON chứa access_token/refresh_token, cấu trúc agent identity có credentials.id_token, mảng nhiều tài khoản, hoặc file JSONL có dòng tiêu đề.

Với agent identity, khóa agent_private_key không được sao chép sang kết quả. id_token được ánh xạ vào cấu trúc đầu ra nhưng không thể thay thế một OAuth access token thực.

JSON này có token đăng nhập. Chỉ dùng trên máy tin cậy và không chia sẻ cho người khác.
